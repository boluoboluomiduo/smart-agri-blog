## 农业农村部关于印发《全国农产品产地市场体系发展“十五五”规划》的通知

发布时间：2026年08月25日

字体：[大  中  小]

各省、自治区、直辖市农业农村（农牧）、畜牧兽医、农垦、渔业厅（局、委），新疆生产建设兵团农业农村局：

为贯彻落实《中华人民共和国国民经济和社会发展第十五个五年规划纲要》、《加快农业农村现代化“十五五”规划》有关部署，加快建设现代农产品产地市场体系，我部编制了《全国农产品产地市场体系发展“十五五”规划》。现印发给你们，请结合实际，认真组织实施。

农业农村部

2026年8月21日

（本文有删减）

全国农产品产地市场体系发展“十五五”规划

农产品产地市场体系立足农产品生产区域，提供交易集散、加工仓储、物流配送、价格信息、品牌营销等综合服务，有效衔接生产与消费，是我国农产品市场和流通网络的重要组成，是保障农产品稳定安全供给的基础支撑。为加快构建高效顺畅的农产品现代流通体系，根据《中华人民共和国国民经济和社会发展第十五个五年规划纲要》、《加快农业农村现代化“十五五”规划》，制定本规划。

# 一、总体要求

坚持以习近平新时代中国特色社会主义思想为指导，深入贯彻党的二十大和二十届历次全会精神，认真落实四中全会部署，全面贯彻习近平总书记关于“三农”工作的重要论述和重要指示精神，完整准确全面贯彻新发展理念，加快构建新发展格局，坚持有效市场和有为政府相结合，坚持纵深推进全国统一大市场建设，锚定农业农村现代化，以保障农产品稳定安全供给、带动农民增收为主要目标，以推进农产品产需衔接、完善农产品现代流通体系为重点任务，推动线上线下融合、产地销地匹配、农业商业互联，完善产地市场设施建设，优化市场营销服务，增强监测预警能力，发展壮大流通主体，高质量推进农产品产地市场体系建设，为扎实推进乡村全面振兴、加快建设农业强国提供有力支撑。

到2030年，契合产业、产需衔接、高效顺畅、内联外通的现代农产品产地市场体系基本建成，农产品供给保障和服务带动小农户能力稳步提升。农产品产地批发市场布局更加合理，交易、冷链、物流等设施持续完善。农产品市场营销服务更加专业，业态模式场景丰富多样，产销精准衔接能力大幅提高。农产品信息监测预警体系更加健全，服务决策和引导预期能力显著提升。农产品流通主体规范化、专业化经营能力明显增强，促进农业生产结构优化、农产品品质提升。农产品产地市场体系标准化、数智化、绿色化水平进一步提高。

到2035年，现代农产品产地市场体系建设取得显著成效，实现农产品产需高效衔接，在保障农产品稳定安全供给、提升农业质量效益和促进农民增收等方面作用更加突出，有力支撑农业农村现代化建设。

二、推动农产品产地市场转型升级

（一）优化提升产地批发市场。支持区域优势产业发展，衔接国家综合立体交通网和重要商品骨干流通走廊，进一步优化农产品产地批发市场发展布局。推进省部共建农产品产地批发市场转型发展，提升物流集散、价格形成、品牌培育等能力，加快建成通达全国、高效顺畅的全国性农产品流通枢纽。优化区域性农产品产地批发市场功能，建成链接城乡、畅通产销的区域集散中心。加强农业农村部定点市场建设管理。鼓励通过联建联营联盟等方式，推动形成平台对接、设施共用和信息共享的产地市场集群，健全完善运营机制，有效对接销地批发市场。

（二）加快完善产地冷链物流设施。完善与国家骨干冷链物流基地、国家物流枢纽等相衔接的产地骨干冷链物流设施，引导农产品加工、冷链物流等企业集聚，成为区域农产品冷链物流重要节点。加强县域产地冷链集配中心建设，完善预冷保鲜、分选分级、仓储配送等功能。在田头建设一批具备预冷、冻结、冷藏、气调等功能的小型固定或移动式仓储设施装备。

（三）建立健全乡村产销服务站点。引导支持农产品经纪人、新型农业经营主体、农村集体经济组织、国有农场等，加快补齐田头市场设施短板，改造提升预冷烘干、清洗分选、仓储保鲜等商品化处理设施装备，建成一批乡村产销服务站点。鼓励现代农事综合服务中心拓展营销服务功能。用好邮政、供销、电商、快递等资源，依托村级寄递物流综合服务站、便民服务站等，促进农产品就地销售。

专栏2农产品产地市场设施建设

1.农产品产地市场集群建设。聚焦重点、因地制宜，以省部共建农产品产地批发市场为引领、区域性产地批发市场为支撑、田头市场或乡村产销服务站点等仓储保鲜设施为基础，构建产销协同联动和联农带农机制，建成50个能够辐射带动区域乃至全国优势产业发展的农产品产地市场集群。特色粮经类重点在黄土高原、东北地区等优势产区，布局马铃薯、杂粮杂豆等产地批发市场，加强现代仓储设施建设；果蔬类重点在黄淮海、环渤海、黄土高原、长江流域、华南地区等优势产区，布局蔬菜、食用菌、苹果、柑橘、猕猴桃、热带水果等产地批发市场，加强产地预冷、商品化处理及大型自动化仓储设施建设；畜产品类重点在东北地区、西北地区、西南地区等优势产区，布局牛羊肉、禽蛋等产地批发市场，加强排酸、冻结、分割及冷藏等加工物流设施建设；水产品类重点在长江流域、珠江流域以及沿海地区等优势产区，布局淡水产品、海水产品等产地批发市场，加强切割、冻结、冷藏、制冰、充氧等设施建设；特色农产品类重点在茶叶、中药材、花卉、香辛料、干果等优势产区布局产地批发市场。

2.农产品产地冷链物流设施建设工程。在产地重要流通节点，培育壮大1500个具有仓储保鲜、初加工、冷链配送能力的产地冷链集配中心。在鲜活农产品生产集中度高、商品化处理需求旺盛的重点村镇，建设一批田头小型冷藏设施。

3.乡村产销服务站点建设。重点依托田头市场、现代农事综合服务中心等建设一批乡村产销服务站点，为农民、新型农业经营主体等提供代购代销、交易结算、商品化处理、质量速测等服务。

# 三、强化农产品市场营销服务

（四）做强线下流通渠道。鼓励农产品产地、集散地、销地批发市场向生产和消费两端延伸，稳定产销关系，拓展服务功能，更好发挥主渠道作用。推动连锁商超、社区菜店等与生产经营主体、农产品经纪人等对接合作，发展订单农业、直采直供等模式，鼓励设立公益直销专区。用好东西部协作、定点帮扶等机制，开展协作帮扶促消费工作。健全鲜活农产品应急销售机制。更好发挥农产品期货价格发现、产业引导作用。

（五）培育农产品消费新业态。丰富消费场景，推动农产品消费融入文化旅游、体育赛事等领域，扩大绿色优质农产品消费。深入实施“数商兴农”和“互联网+”农产品出村进城工程，引导平台企业下沉乡村，拓宽线下线上融合渠道，推广电商直采、社区团购等模式，促进农产品网络销售。鼓励农产品批发市场、商超企业等探索开展农产品首发、首展等促销活动。鼓励开展“个性定制+即时物流”、“预售+集采集配”等新模式。培育丰收市集、优质农产品体验店等业态，营销推广特色优质产品。

（六）加强品牌营销推广。分类推进粮油、果蔬、畜禽、水产等品牌培育。推进农业国家品牌建设，持续开展农业品牌精品培育计划，打造农产品区域公用品牌、农业企业品牌、农产品品牌相互支撑的现代农业品牌矩阵。加强农业品牌推介，用好农业展会、农事节庆等平台，开展中国农业品牌行活动，推动品牌出海。实施农业品牌保护专项行动，强化涉农商标、地理标志、专利技术等品牌保护。开展公益性品牌监测。

（七）加快衔接国际市场。做好内外贸规则机制对接，扩大农产品检验认证互认范围，鼓励国内优势农产品参与国际竞争。用好自由贸易试验区等平台，培育农产品综合性贸易服务企业，在标准认证、市场渠道、知识产权等方面提供一站式服务。鼓励农产品生产经营主体与贸易企业形成合作联盟，共同开拓国际市场。鼓励有条件的农产品批发市场建立海外仓储、分销网络，参与共建“一带一路”国家流通渠道或销售终端建设。支持省部共建农产品产地批发市场打造国际商品集散中心。

专栏3农业品牌提升与消费促进

1.农产品营销服务体系建设。健全营销服务工作机制，建设营销服务队伍，完善产销信息发布、渠道拓展、品牌培育、数字营销、区域合作等服务内容。做强重点活动平台，用好农业展会、农事节庆等载体，发挥农产品产地冷链集配中心、产销服务中心等作用，提升营销服务质量水平。建立农产品应急销售机制，提升应急处置能力。

2.农业品牌提升行动。持续推进农业品牌精品培育计划，壮大500个高标准引领、高水平认证支撑的农业精品品牌，规范提升省级农业品牌目录，完善上下衔接、梯次培育的农业品牌目录体系。深入实施“品牌强农”宣传计划，讲好中国农业品牌故事。

3.农产品消费促进行动。加强农产品消费市场研究，跟踪研判市场消费趋势。发布一批省级消费指南、消费地图，促进品牌产品消费。支持打造集成农业科普、加工体验、非遗展示等沉浸式消费场景，推动多业态融合消费。聚焦蔬菜、水果、水产品、牛肉、乳制品等重点品类，组织“消费周”、“消费月”、“消费季”等引领性、标志性促消费活动。开展“健康饮食、合理膳食”科普宣传。

# 四、增强农产品市场监测预警能力

（八）夯实信息采集基础。加强重点农产品产地、销地、集散地批发市场和大型种养殖企业信息统计，监测农产品来源去向、价格销量、成本收益、库存数量等情况，建立高素质信息员队伍，构建信息直连、数据直报的信息采集体系。用好各类调查方法，应用物联网自动采集、智能移动终端等技术装备，强化数据采集、汇总、审核、清洗全程管理。加快建设全领域覆盖、多层级联通的农业农村大数据平台，推动农产品生产、消费、贸易等数据共享。

（九）强化市场分析预警。加强农产品市场信息监测预警人才培育，构建部级分析师、省级分析员、市县调查员三级联动、专业分工的信息分析队伍。深化人工智能等技术应用，探索建立符合我国农业农村发展特点的信息监测预警新方法、新模型、新工具。指导支持有条件的农产品批发市场建立农产品购销调查分析制度，开展常态化供需形势分析。

（十）提高信息服务效能。指导推动农产品批发市场发布实时价格行情和交易信息，引导生产经营主体、农产品经纪人等合理安排生产销售。做好定期常态信息发布，强化关键农时季节、热点焦点信息动态发布，持续发布农产品批发价格指数、重要农产品市场价格、农产品供需形势分析等权威信息，及时预警市场异动风险。用好传统媒体、新媒体、展会平台等多种渠道，规范发布市场价格指数等数据服务产品。

专栏4农产品信息监测预警能力提升

1.市场信息采集扩面提质行动。建立覆盖30家左右核心农产品批发市场和200家重点农产品批发市场的市场信息采集网络，稳步推进农产品批发市场电子交易数据对接。加强信息员培训，强化源头数据质量核验，提高产地市场信息采集质量。

2.市场信息分析队伍建设。用好科研院所、企业协会等多方力量，建立健全农产品市场信息分析人才队伍，组织开展能力培训，完善队伍建设和管理制度，加大支持力度，聚焦重点品种、重点时段、重点地区，常态化开展农产品批发市场采购、销售、库存、价格等跟踪研判，增强预测预警的前瞻性、科学性、规范性。

3.市场信息发布能力提升。建立分级分层常态化发布机制，按年度发布农业展望报告、按月发布供需分析报告、按周发布国内外农产品市场价格动态和猪肉市场价格快报、按日发布全国鲜活农产品批发价格和“农产品批发价格200指数”，服务生产经营决策，引导市场预期稳定。

# 五、壮大农产品流通队伍

（十一）提升流通企业现代化水平。对标国际一流企业，支持通过战略合作、资源整合等方式，培育一批具有行业影响力的农产品流通领军企业，积极融入全球农产品供应链。引导规模以上农产品流通企业丰富经营内容、突出特色优势，提升仓储物流、加工配送、品牌培育等服务质量。鼓励农产品流通企业带动上下游中小企业、农民合作社等协同发展，形成标准协同、技术互补、信息共享的企业发展阵型，加快推进供应链与产业链深度融合，推进种养加、产供销一体化。

（十二）促进经销商专业化经营。加强农产品经销商培育服务，引导经销商增强管理意识，提升标准化、品牌化经营水平。鼓励有条件的经销商建立现代企业制度，逐步做优做强。推动经销商与农业生产主体建立稳定的产销合作关系，共建共享田头冷藏保鲜、乡村产销服务站点等设施，带动农业增值增效。发挥社团组织的行业引导自律作用，增强诚信经营意识，提高为农服务能力。

（十三）加快经纪人职业化建设。加强引导、组织与服务，培育农产品骨干经纪人，提升产销服务能力。引导农产品经纪人经营方式向产加储运销一体化转变，服务内容向生产指导、技术支持、产后处理等拓展。健全完善国家职业标准，开展专业技能培训，加强职业道德建设，推动农产品经纪人队伍专业化、职业化发展。

（十四）引导农民主播规范化发展。以家庭农场经营者、农民合作社带头人、大中专毕业生等为重点，加强智慧农业、农产品电商、短视频营销、人工智能等新知识、新技能培训，培育一批扎根农村、服务农业的农民主播。引导互联网平台企业，以实操培训、流量扶持、产销衔接、宣传推广等公益方式培育农民主播，加大对失德失范和违规行为约束惩戒力度。推动加强行业自律和标准建设。

专栏5农产品流通队伍建设

1.农产品流通领军企业培育。分行业、分类型建立农产品流通领军企业库，组建农产品流通企业专家服务队伍，举办科企合作、银企对接、经验交流等活动，重点培育110家以上交易额超百亿元的农产品批发市场，带动中小企业、农民合作社及家庭农场融入现代农产品供应链。

2.农产品经纪人赋能提质行动。完善农产品经纪人国家职业标准，依托乡村产业振兴带头人培育“头雁”项目、农村实用人才带头人培训、高素质农民培育计划等开展相关培训，组织开展全国农产品经纪人职业技能竞赛，提升农产品经纪人行业规范意识与专业服务水平。加强设施建设、财税政策、金融扶持、信息服务等方面倾斜支持，推动农产品批发市场、平台企业、金融机构等采取有效措施，共同促进农产品经纪人发展，培育3万名懂市场、会经营、讲诚信、有担当的农产品骨干经纪人。

# 六、推进农产品市场体系数智化发展

（十五）加快数智化技术装备应用。推动农产品批发市场加快智能传感、射频识别等技术集成应用，按需配置智能生产线、智能仓配等设施设备，推广智能化标准托盘和周转设备。积极推进省部共建农产品产地批发市场率先集成应用智慧交易、智慧物流等技术装备，加快探索智能体建设。因地制宜推进山区、丘陵地区探索低空无人机、空天地一体化调度等智慧物流新模式。

（十六）推进“人工智能+”农产品流通发展。充分发挥大型农产品批发市场、“链主”企业、农业产业化龙头企业等作用，探索数字化集采集配、统仓统配等新模式，打造“人工智能+”农产品流通应用场景。加强农产品消费大数据分析与生产端反馈应用，打造面向市场、数据驱动、高效协同的智能供应链。鼓励农产品智慧流通技术研发，推广面向生产经营主体的产销数字化赋能应用，提高农产品流通主体产销协作协同效率。

（十七）加强流通数智化创新能力建设。鼓励涉农高校、科研院所和企业等联合开展农产品流通创新研究，推进数智化、绿色化技术攻关、装备集成和模式优化，加强重要农产品流通数据分析应用。鼓励和引导普通高等学校、职业学校加大农产品流通数智化专业人才培养，增强创新型、复合型人才供给。加强产学研用合作，健全完善农产品流通数智化管理服务标准。

专栏6农产品产地市场体系数智化发展

打造“人工智能+”农产品流通应用场景。鼓励有条件的农产品产地批发市场进行数智化升级，开发推广具有自主知识产权的农产品流通大模型和通用软件工具。推动省部共建农产品产地批发市场建设运营管理智能体，打造一批农产品数字化供应链，形成农产品流通数智化发展模式。

# 七、拓展农产品产地市场体系多种功能

（十八）增强农业生产经营服务能力。鼓励农产品批发市场、农产品流通企业等以自建、合作、订单等方式建立规模化种养基地。健全农产品流通标准体系，引导健全以市场需求为导向的品质评价和质量分级制度，推进品种培优、品质提升、品牌打造和标准化生产。加强农产品质量安全承诺达标合格证的规范开具、使用和查验。引导农产品经纪人、农产品批发市场提供产品规格、市场价格、需求预测等经营服务，拓展代耕代种、统防统治、技术推广等生产服务。

（十九）构筑产业深度融合平台。建立适应一二三产业融合发展需要的农产品产地市场体系，支撑农业产业强镇、现代农业产业园和优势特色产业集群等建设，增强产业价值创造能力。发挥农产品产地批发市场要素集聚、流通高效等优势，带动企业就地就近发展食品加工、净菜加工、中央厨房等业态，促进生产、加工与物流配送紧密衔接。深化农商文体旅融合，鼓励流通主体因地制宜发展农事体验、科学普及、美食品鉴等服务。

（二十）健全应急保供体系。落实“菜篮子”市长负责制，完善“平时服务、急时应急”、“政府储备+市场调节”等长效运行机制，提升农产品供应链安全韧性。因地制宜开展“菜篮子”产品应急保供生产基地和仓储保鲜设施建设，推动符合条件的省部共建农产品产地批发市场、区域性农产品产地批发市场纳入“平急两用”公共基础设施建设，加强与国家储备体系对接。健全农产品批发市场、物流企业、连锁商超等协同协作机制，提升跨区域大规模调运组织能力。

专栏7“菜篮子”产品应急保供能力提升

大中城市“菜篮子”产品应急保供能力建设。严格落实“菜篮子”市长负责制，重点面向京津冀、长三角、粤港澳、成渝等城市群，推动直辖市、计划单列市、省会城市等36个城市健全应急保供机制，完善农产品市场体系建设，建立5000个生产、运销主体组成的“菜篮子”产品应急保供队伍，确保在重要节点、重大事件以及突发情况下“菜篮子”产品稳定供应。
