# 精准培训补短板 守护田间“冷链安全”——全省农业农村系统开展产地冷库安全使用专题培训2026-07-24

近日,全省农产品产地冷库安全使用专题培训班在运城市盐湖区开班。各市、县(区)农业农村部门分管领导及业务负责人参训。本次培训紧扣安全生产月工作要求,聚焦农产品产地冷库管理制度不完善、操作不规范、设施老化、安全意识薄弱等突出问题,以“明职责、查隐患、教方法、压责任”为核心,通过理论授课、互动答疑、现场实操相结合的方式开展靶向培训,精准补齐基层监管工作短板。

开班仪式上,省农业农村厅副厅长高耀东作动员讲话。会议强调,产地冷库是保障农产品仓储保鲜、助农增收的重要基础设施,安全运行事关群众生命财产安全和农业发展大局。结合典型安全事故案例,深入剖析冷库管护、设备运维、规范操作等方面的突出问题,并明确四项工作重点:一是厘清监管职责,抓实冷库使用环节精准监管;二是开展全域摸底排查,动态更新冷库台账,摸清底数实情;三是严格对照《农产品产地冷库使用安全十必看》排查隐患,落实整改闭环管理;四是压实监管和主体双重责任,常态化开展安全宣教与巡查,通过技术升级提升老旧冷库安全水平,坚决杜绝麻痹松懈思想,筑牢农业安全生产防线。

培训期间,行业专家围绕冷库安全管理规范、信息填报标准等内容开展专项授课,逐条解读产地冷库使用安全“十必看”实操要点,将专业规范转化为基层可落地、易操作的工作方法,并通过现场答疑交流,有效破解一线监管难点堵点。

全体参训人员前往运城博萌亮农业发展有限公司和山西奇雄农业发展有限公司开展现场教学,由山西农业大学专业教师分组带队、循环轮训。通过示范讲解、互动研讨、实操演练等方式,详细拆解冷库安全检查流程、监管重点和实操规范,多轮次沉浸式实训确保参训人员学深悟透、熟练掌握实操技能。

参训人员普遍反映,本次培训贴合基层实际、内容务实管用,有效补齐了业务短板、理清了监管思路,大幅提升了冷库安全管理和隐患排查实操能力。下一步,全省农业农村系统将转化落实本次培训成果,全面开展产地冷库使用安全隐患专项大排查,从严压实安全责任,常态化整治风险隐患,全力守护群众生命财产安全,护航全省农业高质量发展。
